    Conectar a la maqueta real

    Con el Arduino conectado por USB, esta misma pantalla muestra el peso real y la etapa del PLC, y sus botones mandan las órdenes al PLC.

    Para usarla, descarga esta página (te la envié como archivo) y ábrela en Chrome o Edge en tu computador.

    El proceso paso a paso

    Doce etapas, de la 0 a la 11. Las de borde ámbar esperan al operador; el resto avanza solo con sensores y tiempos. En el PLC cada etapa es una marca: M0 es la etapa 0, M1 la etapa 1, y así.

    La válvula se cierra antes de la meta porque el producto que ya salió del silo sigue cayendo mientras la compuerta cierra. Esa cantidad es la compensación: si la meta es 500 g y caen unos 50 g después del cierre, la válvula se cierra a los 450 g. La HMI mide la caída real de cada saco y sugiere el ajuste.

    Ideas para el dispensador de pallets

    Las tres usan un almacén vertical (torre) o una rampa, y entregan un pallet por ciclo. El ladder de esta página está hecho para la idea A; abajo de cada idea dice qué cambia si eligen otra.

    Recomendada

    A. Torre + empujador con actuador lineal

    • Los pallets se apilan en una torre con guías. La abertura de abajo deja pasar solo un pallet: alto del pallet + 2 mm.
    • Un actuador lineal de 24 V y 100 mm de carrera empuja el pallet de abajo hasta la correa; los de arriba bajan solos.
    • Dos finales de carrera (adelante X4, atrás X5) y un sensor que avisa si quedan pallets (X3).
    • Para invertir el giro se usan dos relés: Y1 avanza, Y2 retrocede. El ladder impide que se activen juntos.
    La más barata

    B. Torre + biela-manivela con motorreductor

    • Un motorreductor de 24 V con una manivela: cada vuelta completa empuja un pallet y vuelve sola.
    • Un solo relé y un final de carrera de leva que marca la posición de reposo.
    • En el ladder: Y1 se enciende en la etapa 1 hasta que la leva sale y vuelve a pisar el final de carrera (usar LDP X5). Y2 no se usa.
    Sin motor de empuje

    C. Rampa por gravedad + compuerta de escape

    • Los pallets bajan solos por una rampa de unos 15° y los detiene una compuerta.
    • Un solenoide o un servo levanta la compuerta un instante y pasa un pallet.
    • Necesita más largo de maqueta y pallets que deslicen bien (MDF lijado o acrílico).

    Conexiones y lista de entradas y salidas

    El PLC manda la secuencia. El Arduino pesa, decide cuándo cortar y hace de puente con la HMI del computador. Entre el Arduino y el PLC solo van señales on/off, por relés y optoacopladores, para no mezclar 5 V con 24 V.

    El ladder, peldaño por peldaño

    51 peldaños en cinco bloques. Cada etapa del proceso es una marca M que se enciende con SET y apaga la anterior con RST; las salidas se escriben al final, una sola vez cada una. Mientras corre el simulador, los contactos y bobinas activos se pintan en verde.

    contacto NA (LD / AND / OR) contacto NC (LDI / ANI / ORI)

    Construir y probar en GX Works2

    Primero en el simulador del computador, sin cables. Después en el PLC real, entrada por entrada. Así, si algo falla, saben si es el programa o el cableado.

    Parte 1: escribir el programa

    1. Crear el proyecto

      Project → New. Series: FXCPU. Type: FX3U/FX3UC. Project Type: Simple Project. Language: Ladder. Guárdenlo con un nombre como envasadora_lioh.

    2. Cargar los comentarios de los dispositivos

      En el árbol de la izquierda abran Global Device Comment. En “Device Name” escriban X000, copien la lista con el botón “X desde X000” de la sección de conexiones, hagan clic en la celda de comentario de X000 y peguen. Repitan con Y000, M0, M100, T0 y D100. Las filas vacías son direcciones que no se usan. Si su versión no pega varias filas, escríbanlos a mano: son pocos. Con los comentarios, el ladder se lee solo.

    3. Escribir cada peldaño

      Abran Program Setting → MAIN. Pónganse al inicio de la fila, escriban la instrucción tal como aparece en el listado de cada peldaño, por ejemplo LD X2, y presionen Enter: GX Works2 dibuja el contacto y avanza el cursor. Para un OR, bajen el cursor a la fila de abajo, bajo el contacto, y escriban OR X21. Las salidas (SET M100, OUT Y0) se escriben al final de la fila y quedan pegadas a la barra derecha.

      • También pueden usar las teclas: F5 contacto NA, F6 contacto NC, Shift+F5 contacto NA en paralelo, F7 bobina, F8 instrucción (SET, RST, MOV, ZRST, PLS).
      • Un temporizador se escribe como bobina con su tiempo: OUT T0 K50 = 5,0 s (base de 100 ms).
      • Varias salidas del mismo peldaño (SET M2 y RST M1) se escriben una debajo de otra; GX Works2 las pone en paralelo.

    4. Convertir y revisar

      Cada cierto número de peldaños presionen F4 (Convert). Los peldaños grises pasan a blancos cuando quedaron bien. Al final usen Tool → Check Program: avisa si una bobina se repite (por ejemplo Y0 escrito dos veces), un error típico.

    Parte 2: probar en el simulador de GX Works2

    1. Iniciar la simulación

      Debug → Start/Stop Simulation. Se abre GX Simulator2, el programa se carga solo y queda en RUN. Activen el monitoreo con Online → Monitor → Start Monitoring (F3): los contactos activos se ven en azul.

    2. Simular lo que está cableado en NC

      En la máquina real, la emergencia (X0) y el paro (X1) entregan 1 cuando nadie los toca. En el simulador valen 0, así que lo primero es forzarlos a ON: Debug → Modify Value, escriban X0, elijan ON y presionen Set. Repitan con X1, X5 (empujador atrás) y X3 (hay pallets).

    3. Recorrer el ciclo completo

      Sigan la tabla de abajo de arriba hacia abajo. “Pulso” quiere decir poner en ON y luego en OFF. En cada fila revisen que la etapa y las salidas sean las que dice la tabla. Si una fila no da el resultado, el error está en el peldaño de esa transición.

    4. Probar las fallas

      Con la etapa 5 activa (válvula abierta), no activen X24 y esperen 60 s: debe encenderse M101 y la luz roja Y7, y cerrarse Y3. Un pulso en X12 la resetea y el llenado continúa. Pongan X0 en OFF en cualquier momento: todo se apaga y la secuencia vuelve a la etapa 0.

    Parte 3: pasarlo al PLC real

    1. Conectar el cable

      Conecten el cable USB de programación y busquen su puerto COM en el Administrador de dispositivos de Windows. En GX Works2: Connection Destination → Serial USB, elijan ese COM y presionen Connection Test.

    2. Escribir el programa

      Con el selector del PLC en STOP: Online → Write to PLC, marquen Program y Device Comment, y Execute. Pasen el selector a RUN.

    3. Probar las entradas sin motores

      Dejen los relés de los motores sin 24 V. Activen cada sensor y pulsador con la mano y miren que se encienda el LED de esa entrada en el PLC y el contacto en GX Works2 (monitor F3). Así confirman el cableado antes de que algo se mueva.

    4. Probar con movimiento

      Energicen los relés, conecten el Arduino y abran la HMI. Hagan un ciclo a velocidad normal con un saco vacío y otro con producto. Anoten el peso final de 5 sacos y ajusten la compensación con la sugerencia de la HMI.

    Arduino y HMI real

    El Arduino lee la celda con el HX711, le manda el peso a la HMI por USB y activa los relés hacia el PLC. Las señales del PLC (tarar, ciclo activo y número de etapa) le llegan por optoacopladores.

    Pin ArduinoConectado a
    A0, A1HX711: DT y SCK (VCC a 5 V, GND a GND)
    D2 a D7Módulo de 8 relés de 5 V. El contacto NA de cada relé va a X20 a X25 del PLC.
    D8Optoacoplador ← Y10 tarar
    D9 a D12Optoacopladores ← Y20 a Y23, número de etapa en binario
    A2Optoacoplador ← Y11 ciclo activo
    USBComputador con la HMI. También alimenta el Arduino.

    1. Instalar la librería

      En el IDE de Arduino: Herramientas → Administrar bibliotecas, busquen HX711 e instalen la de Bogdan Necula.

    2. Cargar el programa

      Abran pesaje_envasadora.ino (te lo envié como archivo), elijan la placa y el puerto, y súbanlo.

    3. Calibrar

      Con la celda vacía presionen “Calibrar: celda vacía” en la HMI. Pongan un peso conocido de 500 g y presionen “Calibrar con 500 g”. El factor queda guardado en la EEPROM.

    Relés. Casi todos los módulos de relés baratos se activan con nivel bajo. El programa ya viene así. Si al encender el Arduino los relés quedan activados, cambien RELE_ON a HIGH. Alimenten la bobina de los relés (JD-VCC) con 5 V aparte, por ejemplo con un reductor LM2596 desde los 24 V: el USB no alcanza para varios relés a la vez.

    /*
  Envasadora LiOH (maqueta) - Pesaje y enlace HMI <-> PLC
  Placa: Arduino Uno o Nano
  Libreria: "HX711 Arduino Library" de Bogdan Necula (Gestor de librerias)

  Que hace:
   - Lee la celda de carga con el HX711 y calcula el peso en gramos.
   - Envia el peso y la etapa del PLC a la HMI (computador) por USB, 10 veces por segundo.
   - Recibe los botones de la HMI (PARTIR, MARCHA, PARO, RESET) y los pasa al PLC con reles.
   - Avisa al PLC con un rele cuando el peso llega al punto de corte (meta - compensacion).
   - Avisa al PLC con otro rele si el peso final queda fuera de tolerancia.
   - Hace la tara cuando el PLC activa la salida Y10.

  Conexiones (resumen):
   HX711:  DT -> A0, SCK -> A1, VCC -> 5V, GND -> GND
   Reles hacia el PLC (modulo de reles 5 V, contacto NA en serie con la entrada X):
     D2 -> X20 PARTIR   D3 -> X21 MARCHA   D4 -> X22 PARO
     D5 -> X23 RESET    D6 -> X24 PESO DE CORTE   D7 -> X25 FUERA DE TOLERANCIA
   Senales desde el PLC (modulo optoacoplador PC817, salida baja = activo):
     Y10 TARAR -> D8    Y20 -> D9   Y21 -> D10   Y22 -> D11   Y23 -> D12 (codigo de etapa)
     Y11 CICLO ACTIVO -> A2

  Comandos por el monitor serie (115200 baudios, fin de linea "Nueva linea"):
   P  = PARTIR      M = MARCHA      S = PARO      R = RESET
   SP 500 = meta en gramos         CO 50 = compensacion (corte anticipado) en gramos
   TL 15  = tolerancia +/- gramos  Z = poner en cero (sin saco)
   CAL0   = paso 1 de calibracion (celda vacia)
   CAL 500 = paso 2 de calibracion (con un peso conocido de 500 g encima)
*/

#include <HX711.h>
#include <EEPROM.h>

// ---------- Pines ----------
const uint8_t PIN_DT  = A0;
const uint8_t PIN_SCK = A1;

const uint8_t R_PARTIR = 2;
const uint8_t R_MARCHA = 3;
const uint8_t R_PARO   = 4;
const uint8_t R_RESET  = 5;
const uint8_t R_CORTE  = 6;
const uint8_t R_TOL    = 7;

const uint8_t IN_TARA = 8;
const uint8_t IN_B0   = 9;
const uint8_t IN_B1   = 10;
const uint8_t IN_B2   = 11;
const uint8_t IN_B3   = 12;
const uint8_t IN_RUN  = A2;

// La mayoria de los modulos de reles chinos se activan con nivel BAJO.
// Si tu modulo se activa con nivel ALTO, cambia esto a HIGH.
const uint8_t RELE_ON  = LOW;
const uint8_t RELE_OFF = (RELE_ON == LOW) ? HIGH : LOW;

const unsigned long PULSO_MS = 300;   // duracion del pulso de los botones de la HMI

// ---------- Parametros guardados en EEPROM ----------
struct Config {
  uint16_t marca;      // 0xA5A5 = configuracion valida
  float factor;        // factor de calibracion del HX711
  int16_t meta;        // gramos
  int16_t comp;        // gramos de compensacion
  int16_t tol;         // +/- gramos
};
Config cfg;

HX711 balanza;
float peso = 0;               // peso filtrado en gramos
bool pesoValido = false;

// pulsos no bloqueantes
unsigned long finPulso[8] = {0};

// lectura de etapa con filtro
uint8_t etapa = 0, etapaLeida = 0, etapaPrevia = 0;
uint8_t repeticiones = 0;
bool cicloActivo = false;
bool taraPrevia = false;

// registro del ultimo saco
float pesoEnCorte = 0;
float pesoFinal = 0;

unsigned long ultimoEnvio = 0;
String linea = "";

void guardarConfig() { EEPROM.put(0, cfg); }

void cargarConfig() {
  EEPROM.get(0, cfg);
  if (cfg.marca != 0xA5A5 || isnan(cfg.factor) || cfg.factor == 0) {
    cfg.marca = 0xA5A5;
    cfg.factor = 420.0;   // valor inicial aproximado; calibrar con CAL0 y CAL 500
    cfg.meta = 500;
    cfg.comp = 50;
    cfg.tol = 15;
    guardarConfig();
  }
}

void pulsar(uint8_t pin) {
  digitalWrite(pin, RELE_ON);
  finPulso[pin - 2] = millis() + PULSO_MS;
}

void atenderPulsos() {
  for (uint8_t pin = R_PARTIR; pin <= R_RESET; pin++) {
    if (finPulso[pin - 2] && (long)(millis() - finPulso[pin - 2]) >= 0) {
      digitalWrite(pin, RELE_OFF);
      finPulso[pin - 2] = 0;
    }
  }
}

bool activo(uint8_t pin) { return digitalRead(pin) == LOW; }  // optoacoplador tira a GND

uint8_t leerEtapa() {
  return (activo(IN_B0) ? 1 : 0) | (activo(IN_B1) ? 2 : 0) |
         (activo(IN_B2) ? 4 : 0) | (activo(IN_B3) ? 8 : 0);
}

void leerPeso() {
  if (!balanza.is_ready()) return;
  float g = balanza.get_units(1);
  if (!pesoValido) { peso = g; pesoValido = true; }
  else peso = peso * 0.6 + g * 0.4;   // filtro simple
}

void tarar() {
  balanza.tare(5);   // unos 0,5 s a 10 lecturas por segundo
  peso = 0;
}

void procesarComando(String c) {
  c.trim();
  c.toUpperCase();
  if (c == "P") pulsar(R_PARTIR);
  else if (c == "M") pulsar(R_MARCHA);
  else if (c == "S") pulsar(R_PARO);
  else if (c == "R") pulsar(R_RESET);
  else if (c == "Z") tarar();
  else if (c.startsWith("SP ")) { cfg.meta = constrain(c.substring(3).toInt(), 10, 2000); guardarConfig(); }
  else if (c.startsWith("CO ")) { cfg.comp = constrain(c.substring(3).toInt(), 0, 500); guardarConfig(); }
  else if (c.startsWith("TL ")) { cfg.tol  = constrain(c.substring(3).toInt(), 1, 200); guardarConfig(); }
  else if (c == "CAL0") {
    balanza.set_scale();      // factor 1
    balanza.tare(10);
    Serial.println(F("{\"msg\":\"Celda en cero. Ponga el peso conocido y envie CAL <gramos>\"}"));
  }
  else if (c.startsWith("CAL ")) {
    float conocido = c.substring(4).toFloat();
    if (conocido > 0) {
      float lectura = balanza.get_value(10);
      cfg.factor = lectura / conocido;
      balanza.set_scale(cfg.factor);
      guardarConfig();
      Serial.print(F("{\"msg\":\"Calibrado. Factor = "));
      Serial.print(cfg.factor, 3);
      Serial.println(F("\"}"));
    }
  }
}

void leerSerie() {
  while (Serial.available()) {
    char ch = Serial.read();
    if (ch == '\n' || ch == '\r') {
      if (linea.length()) procesarComando(linea);
      linea = "";
    } else if (linea.length() < 32) {
      linea += ch;
    }
  }
}

void enviarEstado() {
  Serial.print(F("{\"w\":"));   Serial.print(peso, 1);
  Serial.print(F(",\"st\":"));  Serial.print(etapa);
  Serial.print(F(",\"run\":")); Serial.print(cicloActivo ? 1 : 0);
  Serial.print(F(",\"cut\":")); Serial.print(digitalRead(R_CORTE) == RELE_ON ? 1 : 0);
  Serial.print(F(",\"tol\":")); Serial.print(digitalRead(R_TOL) == RELE_ON ? 1 : 0);
  Serial.print(F(",\"sp\":"));  Serial.print(cfg.meta);
  Serial.print(F(",\"co\":"));  Serial.print(cfg.comp);
  Serial.print(F(",\"tl\":"));  Serial.print(cfg.tol);
  Serial.println(F("}"));
}

void setup() {
  Serial.begin(115200);
  for (uint8_t pin = R_PARTIR; pin <= R_TOL; pin++) {
    digitalWrite(pin, RELE_OFF);   // primero el nivel, despues el modo: el rele no parpadea al encender
    pinMode(pin, OUTPUT);
  }
  pinMode(IN_TARA, INPUT_PULLUP);
  pinMode(IN_B0, INPUT_PULLUP);
  pinMode(IN_B1, INPUT_PULLUP);
  pinMode(IN_B2, INPUT_PULLUP);
  pinMode(IN_B3, INPUT_PULLUP);
  pinMode(IN_RUN, INPUT_PULLUP);

  cargarConfig();
  balanza.begin(PIN_DT, PIN_SCK);
  balanza.set_scale(cfg.factor);
  tarar();
  Serial.println(F("{\"msg\":\"Pesaje listo\"}"));
}

void loop() {
  leerSerie();
  atenderPulsos();
  leerPeso();

  // Etapa del PLC: se acepta cuando se lee igual 3 veces seguidas
  uint8_t e = leerEtapa();
  if (e == etapaLeida) { if (repeticiones < 3) repeticiones++; }
  else { etapaLeida = e; repeticiones = 0; }
  if (repeticiones >= 3) etapa = etapaLeida;
  cicloActivo = activo(IN_RUN);

  // Tara: al activarse Y10 (flanco de subida)
  bool tara = activo(IN_TARA);
  if (tara && !taraPrevia) tarar();
  taraPrevia = tara;

  // Senal de corte: peso >= meta - compensacion
  bool corte = pesoValido && peso >= (cfg.meta - cfg.comp);
  digitalWrite(R_CORTE, corte ? RELE_ON : RELE_OFF);

  // Senal de fuera de tolerancia: |peso - meta| > tolerancia
  bool fuera = pesoValido && fabs(peso - cfg.meta) > cfg.tol;
  digitalWrite(R_TOL, fuera ? RELE_ON : RELE_OFF);

  // Registro del saco: peso al cortar y peso final estable
  if (etapa != etapaPrevia) {
    if (etapaPrevia == 5 && etapa == 6) pesoEnCorte = peso;
    if (etapaPrevia == 6 && (etapa == 7 || etapa == 15)) {
      pesoFinal = peso;
      Serial.print(F("{\"evt\":\"fin\",\"wcut\":")); Serial.print(pesoEnCorte, 1);
      Serial.print(F(",\"wfin\":")); Serial.print(pesoFinal, 1);
      Serial.println(F("}"));
    }
    etapaPrevia = etapa;
  }

  if (millis() - ultimoEnvio >= 100) {
    ultimoEnvio = millis();
    enviarEstado();
  }
}
